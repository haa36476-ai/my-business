# my-business — الموقع التجاري

موقع تجاري عربي (RTL) لمؤسسة افتراضية، من **ثلاث صفحات**:

| الصفحة | المحتوى |
|--------|---------|
| `index.html` | اسم النشاط + نبذة + الخدمات الثلاثة |
| `works.html` | معرض الأعمال: 3 بطاقات (عنوان، سطر، صورة) |
| `contact.html` | رقم الهاتف، الواتساب، البريد، والعنوان |

- **اللون الأساسي:** `#1f5a7a`
- **الخط:** [Cairo](https://fonts.google.com/specimen/Cairo)
- **الصور:** WebP أقل من 200 كيلوبايت داخل `assets/images/`

## التشغيل

افتح `index.html` في المتصفح، أو شغّل خادمًا محليًا:

```bash
py -m http.server 8000
```
